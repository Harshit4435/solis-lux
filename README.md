# VITTORIS — Architectural Solar & Clean Energy Platform

> **Where Visionary Property Owners & Solar Innovators Converge.**  
> A luxury architectural solar visibility exchange and stakeholder matchmaking platform featuring official **Vittoris** branding, inspired by high-end editorial aesthetics and motion design.

---

## 🌟 Overview & Purpose

**Vittoris** serves as a premier showcase and visibility platform where:
- **Property Owners** (Luxury Estates, Commercial Headquarters, Industrial Campuses, and Agricultural Farmland) can discover bespoke architectural solar installations, BIPV solar glass, and battery microgrids.
- **Solar Asset Owners & Certified EPC Developers** can showcase verified commissioned capacity, technical specifications, and offer direct consultations.
- **Direct Matchmaking**: Users and solar plant owners can connect directly to schedule **Virtual Consultations**, **On-Site Solar Feasibility Audits**, and **Owner-Host Co-Development Partnerships** without intermediaries.

---

## ⚡ Key Highlights & Features

- **Editorial Luxury Design System**: Deep carbon noir (`#08090A`), Champagne Solar Gold (`#D4AF37`, `#E5C158`), and clean Eco-Emerald (`#10B981`) accents.
- **Dark / Light Mode**: Seamless theme switching with custom CSS design tokens.
- **Kinetic Typography & Motion**: *Playfair Display* editorial serif paired with *Manrope* sans-serif, **Lenis** inertia scrolling, and **Framer Motion** scroll reveals.
- **Curated Solar Portfolio (`/projects`)**: Filterable by `Residential Estate`, `Commercial Microgrid`, `Architectural BIPV (Solar Glass)`, and `Agri-PV Farm` with instant keyword search.
- **Technical Blueprints (`/projects/:id`)**: Detailed specifications on Tier-1 N-Type TOPCon bifacial modules, modular liquid-cooled LFP BESS storage, zero roof-penetration mounts, and payback forecasts.
- **Interactive Solar Feasibility Engine**: Dynamic area slider (800 to 50,000 sq ft) calculating real-time kWp output, annual MWh generation, financial tariffs saved, and mature tree planting equivalence.
- **Direct Matchmaking Scheduler (`MeetOwnerModal`)**: Universal appointment scheduling modal matching property seekers directly with lead engineers and plant owners.
- **Technical Dossier Download (`BrochureModal`)**: Lead capture modal for single-line electrical schematics and PVSyst simulation data.
- **Verified Owners Directory (`/owners`)**: Accredited EPC license holders and solar asset owners.
- **Planetary ESG Impact (`/impact`) & Advisory Desk (`/contact`)**.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Routing**: [React Router DOM v7](https://reactrouter.com/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) with `@tailwindcss/vite`
- **Smooth Scrolling**: [Lenis](https://lenis.darkroom.engineering/)
- **Motion & UI**: [Framer Motion](https://www.framer.com/motion/) + [Lucide React](https://lucide.dev/)
- **Language**: TypeScript

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/Harshit4435/solis-lux.git
cd solis-lux
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) (or the port shown in your terminal).

### 4. Build for Production
```bash
npm run build
```
The optimized static production assets will be built in the `dist/` directory.

---

## 🌐 Deployment

You can deploy this repository instantly to **Vercel**:

1. Go to [vercel.com/new](https://vercel.com/new).
2. Select your repository `Harshit4435/solis-lux`.
3. Keep default Vite settings and click **Deploy**.
